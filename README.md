# Forest Escape 2.0｜松林・椰影海岸・雨幕山洞

在原本 1.0.1 的單頁 Three.js 網站上擴充，保留自由移動、觸控方向鍵、日夜設定、畫質設定、沉浸模式與 YouTube 播放器。

## 更新內容

- 松林營地：保留帳篷、營火和小徑，加入暮色螢火蟲、倒木和林地細節。樹冠交叉平面每棵從 5 片減為 3 片，近景枝條樹數從 65 減為 32，降低透明材質和物件繪製負擔。沒有宣稱已量測 FPS 改善。
- 椰影海岸：椰子樹、茅草酒吧、木製吧台、座椅、瓶罐、暖燈、沙灘和動態海浪，三個觀景點。
- 雨幕山洞：拱形岩洞、洞內柴火與火星、木座椅、洞外雨幕和岩石，三個觀景點。雨粒子只分布在洞外。
- 原本固定高頻振盪器蟲鳴及合成噪音改為七個隨站提供的自然錄音，依場景搭配三軌音量。首次播放才載入；同一分頁內快取。
- 音效循環邊界採約兩秒重疊淡入淡出；音量調整與場景轉換採平滑增益。失敗可重試，不偷偷改回合成聲。
- 場景首次選取時建立，後續切換重用；減少動態偏好會停止海浪、雨線、火星等動態效果。

## 更新 GitHub Pages

1. 先備份原本的 `index.html`。
2. 將本壓縮檔解壓縮後的 **index.html、assets 資料夾、README.md、AUDIO_CREDITS.md** 上傳到原儲存庫根目錄。不要只上傳 index.html，音效需要整個 assets/audio 資料夾。
3. 保留原本 GitHub Pages 的分支和根目錄設定，提交後等部署完成。
4. 開啟 https://lting025.github.io/Forest_Escape.github.io/ ，按 Ctrl+F5 更新快取。
5. 點「開始放鬆」，在「營地」頁籤上方的選單切換三個場景。「自然聲音」可調整各軌音量。

本版未直接推送或部署至你的 GitHub。

## 本機預覽

在解壓縮的資料夾開啟終端機，執行 `python -m http.server 8000`，然後開啟 http://localhost:8000 。請勿直接雙擊 HTML（file:// 無法正常載入錄音與 YouTube）。3D 引擎仍從固定版本 CDN 載入，需要網路。

## 已完成驗證與限制

- JavaScript 語法檢查通過。
- 使用實際 Three.js r180 核心，在無 GPU 的測試中建構三個場景並多次切換；檢查三種光線、三種畫質、九個觀景點的移動邊界、動畫數值與場景重用。畫布紋理與介面由測試替身代替，這不等於視覺驗收。
- 七個 MP3 以 ffprobe 檢查並以 ffmpeg 完整解碼通過。
- 預覽瀏覽器沒有可用 WebGPU／WebGL 圖形環境，初始化無法建立 renderer；未完成實際畫面、陰影、FPS、耳機試聽、手機效能或 YouTube 播放驗收。
- 請在支援 WebGPU／WebGL 2、已開啟硬體加速的電腦驗收：依序切換三個場景、觀景點和日夜；試聽音效至少三分鐘以確認循環接縫；測試靜音、暫停、切換分頁與音樂。
- 為了快速切換，已造訪的場景與已解碼的錄音保留至關閉分頁；低記憶體手機可能仍需降低畫質。
- 自然音在分頁進入背景時暫停。YouTube 仍受官方播放器、影片授權與瀏覽器政策限制。

音效來源與授權見 [AUDIO_CREDITS.md](AUDIO_CREDITS.md)。三維模型、紋理與動畫由程式生成，不是實景攝影。
